シンプル版ポートフォリオ（エフェクトなし）

残したもの:
・元のトップ画像とその配置 / 天気に応じた背景色
・AboutとWorks / カテゴリ絞り込み / 並び替え
・作品詳細ポップアップ（クリックして開く / ×・Escで閉じる）

削除したもの:
・カーソルの水色の粒 (p5.js / sketch.js)
・スクロールでふわっと表示する機能 (effects.js)

使い方:
1. 元のmediaフォルダを、このフォルダにコピーしてください。画像は同梱していません。
2. index.htmlをダブルクリックして開いてもWorksが表示されます。
3. GitHubに公開する場合は、index.html / style.css / works.js / works.csv / mediaフォルダをアップロードします。
4. 作品を編集する場合: Web公開時はworks.csvを編集。ファイルから直接開く場合も同じ内容にしたければworks.js冒頭のdefaultWorksも編集してください。

注意: CSVのカンマ入り文章には対応していません（元のCSV形式を継承）。
